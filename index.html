Cómo se juega

  1. Objetivo: que cada fila del tablero tenga fichas de un único tipo (misma forma y color).
  2. Movimiento: intercambia dos fichas de distinto tipo, estén donde estén. Arrastra una sobre la otra, o tócalas una tras otra. Al elegir una, las de su mismo tipo se atenúan.
  3. Ayudas: la marca ✓ indica una fila completa; Pista marca con ⇄ un intercambio útil y Deshacer (Ctrl+Z) vuelve atrás el último movimiento.
  4. Siempre tiene solución: de cada tipo hay fichas justas para llenar filas enteras.
  5. Ajustes: puedes cambiar la dimensión del tablero, el tamaño y el aspecto de las fichas; cada cambio empieza una partida nueva.
